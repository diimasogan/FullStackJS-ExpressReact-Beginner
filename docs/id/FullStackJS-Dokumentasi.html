Ringkasan eksekutif

FullStackJS Express + React adalah project full-stack JavaScript untuk pemula: REST API dengan Express, Prisma, dan MySQL, serta aplikasi React (single-page) untuk registrasi, login dengan JWT, dan mengelola user lewat area admin yang terproteksi.

Repositori ini juga berisi FundamentalES6, kumpulan latihan kecil JavaScript modern yang menjadi dasar project ini.

Fitur

Registrasi & login

Daftar dengan nama, e-mail, dan password; login untuk mendapatkan JWT yang disimpan di cookie.

Route terproteksi

Halaman admin mengarahkan ke login jika tidak ada token; API menolak request tanpa token yang valid.

Kelola user (CRUD)

Lihat, tambah, ubah, dan hapus user dari area admin.

Validasi di server

express-validator mengecek field wajib, format e-mail, e-mail unik, dan panjang password.

Hash password

Password di-hash dengan bcrypt sebelum disimpan.

Demo live

Aplikasi React asli berjalan di GitHub Pages dengan backend yang disimulasikan di browser.

Referensi API

Base URL http://localhost:3000. Endpoint terproteksi membutuhkan JWT di header Authorization (token langsung, tanpa “Bearer”).

MethodEndpointAuthBodySukses
POST/api/register—name, email, password201 Register successfully
POST/api/login—email, password200 { user, token }
GET/api/admin/usersJWT—200 daftar user (terbaru dulu)
POST/api/admin/usersJWTname, email, password201 User created successfully
GET/api/admin/users/:idJWT—200 { id, name, email }
PUT/api/admin/users/:idJWTname, email, password200 User updated successfully
DELETE/api/admin/users/:idJWT—200 User deleted successfully

Respons error

HTTPKapanBody
422Validasi gagal{ success: false, message: "Validation error", errors: [{ path, msg, ... }] }

404Login dengan e-mail yang tidak terdaftarUser not found

Contoh

curl -X POST http://localhost:3000/api/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@demo.com", "password": "password"}'

# use the token from the response
curl http://localhost:3000/api/admin/users -H "Authorization: <token>"

Demo live

GitHub Pages hanya bisa menyajikan file statis, sehingga server Express dan MySQL tidak bisa berjalan di sana. Karena itu build demo mengganti adapter jaringan axios dengan services/mockApi.js.

  • Kode React sama dengan saat pengembangan lokal — hanya jalur pengirimannya yang berubah.
  • mockApi.js meniru setiap controller dan validator: route, status code, pesan, dan format error express-validator yang sama.
  • Data disimpan di browser pengunjung (localStorage). Reset data di banner demo mengembalikan user contoh.
  • Login demo: admin@demo.com / password.
  • Di-build dan di-deploy otomatis oleh GitHub Actions (.github/workflows/pages.yml) dengan VITE_DEMO=true. Build biasa tidak berisi kode demo.

Menjalankan di lokal

  1. Buat database MySQL bernama db_express.
  2. Salin backend-express/.env.example menjadi .env lalu isi DATABASE_URL dan JWT_SECRET.
  3. Jalankan API (port 3000):
cd backend-express
npm install
npx prisma migrate dev
node index.js
  1. Jalankan aplikasi React (Vite dev server):
cd frontend-react
npm install
npm run dev

Untuk mencoba mode demo di lokal: VITE_DEMO=true npm run dev.

Keterbatasan & perbaikan

Sudah diperbaiki

  • Halaman tambah dan ubah membaca token saat request dikirim (sebelumnya dibaca sekali saat file dimuat, sehingga request tepat setelah login tidak membawa token).
  • Halaman ubah mengirim token saat memuat data user, sehingga tetap berfungsi saat dibuka langsung atau di-refresh.
  • backend-express/.env tidak lagi disimpan di repo; gunakan .env.example.

Ide langkah berikutnya

Sembunyikan hash password

Register, create, dan update mengembalikan user lengkap termasuk hash password — pilih hanya id, nama, dan e-mail.

Penyimpanan token lebih aman

Gunakan cookie HttpOnly yang di-set server dan skema standar Bearer.

Tangani token kedaluwarsa

Logout otomatis saat API menjawab 401.

Password opsional saat ubah

Izinkan mengubah nama atau e-mail tanpa mengisi ulang password.

404 untuk id yang tidak ada

Kembalikan 404, bukan 500, saat id user tidak ada.

Deploy backend

Host API dan database MySQL terkelola agar demo bisa memakai backend sungguhan.
