# FullStackJS-ExpressReact-Beginner

A beginner full-stack JavaScript project: a **REST API with Express + Prisma + MySQL** and a **React (Vite) app** with registration, JWT login and user management (CRUD).

- 🖥️ **Live demo:** https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/ — log in with `admin@demo.com` / `password`
  (the backend is simulated in the browser, see `frontend-react/src/services/mockApi.js`)
- 📄 **Documentation:** [English](https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/docs/FullStackJS-Documentation.html) · [Bahasa Indonesia](https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/docs/id/FullStackJS-Dokumentasi.html)

| Folder | Contents |
|---|---|
| `backend-express/` | REST API (Express, Prisma, MySQL, JWT). Copy `.env.example` to `.env` |
| `frontend-react/` | React + Vite app |
| `FundamentalES6/` | Modern JavaScript (ES6+) exercises |
| `docs/` | Documentation in English and Indonesian (generated by `docs/_source/build_docs.py`) |

## Run locally

```bash
# 1. API (port 3000) — needs a MySQL database named db_express
cd backend-express
cp .env.example .env        # then set DATABASE_URL and JWT_SECRET
npm install
npx prisma migrate dev
node index.js

# 2. React app
cd ../frontend-react
npm install
npm run dev                 # or: VITE_DEMO=true npm run dev  (no backend needed)
```
