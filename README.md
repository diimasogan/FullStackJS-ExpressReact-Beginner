# FullStackJS-ExpressReact-Beginner

Project full-stack JavaScript untuk pemula: **REST API Express + Prisma + MySQL** dan **aplikasi React (Vite)** dengan registrasi, login JWT, dan manajemen user (CRUD).

- 🖥️ **Demo live:** https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/ — login `admin@demo.com` / `password`
  (backend disimulasikan di browser, lihat `frontend-react/src/services/mockApi.js`)
- 📄 **Dokumentasi:** [English](https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/docs/FullStackJS-Documentation.html) · [Bahasa Indonesia](https://diimasogan.github.io/FullStackJS-ExpressReact-Beginner/docs/id/FullStackJS-Dokumentasi.html)

| Folder | Isi |
|---|---|
| `backend-express/` | REST API (Express, Prisma, MySQL, JWT). Salin `.env.example` menjadi `.env` |
| `frontend-react/` | Aplikasi React + Vite |
| `FundamentalES6/` | Latihan JavaScript ES6 |
| `docs/` | Dokumentasi EN + ID (dibuat oleh `docs/_source/build_docs.py`) |
